# Assignment #6 — jQuery

**Student:** Mansur  
**Group:** SE-2527

## Description

This project demonstrates the use of jQuery for DOM selection, CSS changes,
visibility effects, fading, sliding, DOM manipulation, form interaction,
animations, and an interactive image gallery.

## How to run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Make sure you have an internet connection so the jQuery CDN and gallery images can load.

No build tools or additional dependencies are required.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload the project files and folders, keeping the structure unchanged.
3. Open **Settings → Pages** in the repository.
4. Select **Deploy from a branch**.
5. Choose the `main` branch and the `/ (root)` folder, then save.
6. Open the published GitHub Pages URL after deployment finishes.

## Tasks included

- **Part 1:** jQuery setup, selectors, `.text()`, `.html()`, and `.css()`.
- **Part 2:** `.hide()`, `.show()`, `.toggle()`, fade methods, and slide methods.
- **Part 3:** `.append()`, `.prepend()`, `.remove()`, attribute changes, and live form output.
- **Part 4:** Basic, sequential, and combined `.animate()` examples.
- **Part 5:** Interactive image gallery with fade transitions.
